# Gage Against The Machine  
💧 *Predicting water turbidity with machine learning* 🤖  

---

## 🌊 Project Overview  
**Gage Against The Machine** is a supervised regression model designed to predict **water turbidity** using real-world hydrological data. By leveraging machine learning, we analyze trends in streamflow, gage height, temperature, and nitrate levels to forecast water clarity.  

---

## 📊 Features & Data  
We use a dataset with the following key features:  

- 📅 **Date** – Timestamp of the measurement  
- 🌡️ **Temperature** – Water temperature at the site  
- 📏 **Gage Height** – Water level at the measurement site  
- 🌊 **Discharge Rate** – Volume of water flowing per unit time  
- 🔬 **Nitrate Concentration (optional)** – Measures nutrient pollution  
- 🏞️ **Upstream Data (optional)** – Previous day's readings for better context
